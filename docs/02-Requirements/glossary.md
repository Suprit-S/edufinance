# Glossary

Sorted alphabetically.

| Term | Definition |
|---|---|
| **Affordability check** | Estimate whether the minimum part-payment of a loan can be paid this month: average monthly surplus of the last 3 complete months, minus a 20 % safety buffer, compared with the minimum part-payment. |
| **Base currency** | The currency of the country where the student lives and studies (e.g. EUR in Germany). All reports and the monthly target are shown in it. |
| **Burn rate** | Average daily spending of a wallet over the last 30 days (expenses only; transfers to own wallets are excluded). |
| **Category** | A label for income or expenses (e.g. *Rent*, *Part-time salary*). System categories are predefined; users can add their own. |
| **Cost of going abroad** | Total spending in the phases *Pre-departure* and *Settling in*. |
| **Cost of the degree** | Total spending from planning start until the study end date. |
| **Earned** | Income that counts towards the Target to Earn: salary, family support, scholarships, refunds. Not earned: loan disbursements and transfers between own wallets. |
| **Effective rate** | The exchange rate a student really got in a transfer: amount received ÷ amount sent. It includes the provider's margin. |
| **EMI (Equated Monthly Instalment)** | The fixed monthly loan payment that covers interest and principal. |
| **Estimated rate** | An exchange rate taken from an older cache entry or the offline fallback table because no current market rate was available. Shown with the label "estimated". |
| **Exchange rate (market rate)** | The mid-market rate between two currencies on a day, provided by the exchange-rate service. |
| **Hidden cost** | The difference between what a transfer would have yielded at the market rate and what was actually received (plus fees), shown in the base currency. A negative value means the rate was better than the market rate. |
| **Home currency** | The currency of the student's home country (e.g. INR). Education loans and family support are usually in it. |
| **Interest saved** | Interest that will not have to be paid because of a part-payment: the remaining interest without the extra payment minus the remaining interest with it, both repaid at the normal EMI. |
| **Life phase** | A period of the student's journey: *Pre-departure*, *Settling in*, *Study*, *Job search*, *Work*, or a custom phase. Every transaction belongs to one phase. |
| **Master table** | A reference table (currencies, countries, categories) that user input is validated against. |
| **Minimum monthly target** | The sum of all Monthly Plan obligations valid in a month (including loan EMIs), converted to the base currency: the least the student must earn that month. |
| **Minimum part-payment** | The smallest extra repayment the student wants to make on a loan; set per loan and used by the affordability check. |
| **Monthly Plan** | The list of recurring monthly obligations (rent, insurance, EMIs, …). |
| **Moratorium** | A period (usually during studies) in which no EMI is due on an education loan, while interest may still accrue. |
| **Outstanding amount** | The loan principal still owed. Maintained by the user and reduced automatically by recorded payments. |
| **Part-payment (prepayment)** | An extra payment towards a loan's principal in addition to the EMI; it shortens the loan and saves interest. |
| **Plan vs. actual** | Comparison of each Monthly Plan line with what was really paid in the month. |
| **Proof of funds (blocked account)** | Money a student must deposit before the visa is granted (in Germany a *Sperrkonto*), released in monthly amounts after arrival. |
| **Rate freezing** | Saving the exchange rate with a transaction permanently, so past values never change when market rates change. |
| **Remittance** | A transfer of money between currencies, e.g. from parents in India (INR) to the student's account in Germany (EUR). |
| **Runway** | Number of days a wallet's balance lasts at the current burn rate. |
| **Safety buffer** | Share of the average surplus (default 20 %) that the affordability check keeps back for unexpected costs. |
| **Surplus** | Earned minus spent in a month. |
| **Transfer (own wallets)** | Money moved between two of the student's own wallets; neither income nor expense. |
| **Wallet** | A named pot of money in exactly one currency, e.g. "Daily Spending – EUR" or "Home Account – INR". |
| **Wallet status** | Classification of runway: Healthy (> 90 days), OK (60–90), Warning (30–60), Critical (< 30). |
